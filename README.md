# 荒野日记 · 孤岛重制版

本地纯前端生存游戏，采用 Vite + React + TypeScript + Tailwind CSS + Lucide。美术为代码 SVG，声音为 Web Audio 合成，没有外部图片、字体或声音请求。

## 启动

双击 `启动游戏.cmd`，或在此目录运行：

```powershell
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；规则验证：`npm test`。

## 开始游玩

1. 初始位于营地，有小刀、火把、食物与基本建材。先建净水捕兽设施，探索海岸和竹林，再制造、装备竹枪。
2. 地图选区后点击“整装出发”；抵达后“深入探索”。前四层遭遇普通敌人，第五层为守关战和事件。清关后可反复采集、重访天气事件。
3. 竹枪在距离2突刺可压制近战敌人。远程武器要同时携带对应弹药。战斗中右侧行囊可吃喝治疗，会受到一次反击。
4. 营地制造从背包和储物箱共同取材；离营后仅能使用背包物品。出门前在行囊取出补给、装备、火把。回家可一键存入战利品，已装备物品和随身火把、面具、背包保留。
5. 20:00—22:00入睡恢复更多。每三天夜间有野兽袭营，修复栅栏保护储粮。外伤和内伤数值越高越健康。
6. 伙伴面板管理白狼、骆驼和库鲁；营地或伙伴页面的逃生工程列出每个结局的实时条件。
7. 明暗盘初始可在三步内解开。十步以内开放研究所；超过十步激活火山。两种分支都给图纸和四星龙珠；快速解谜后也可主动激活地脉，避免锁死其他结局。隔热舱准备完成后允许立即引爆逃生。
8. 一星龙珠需晴天海岸；二星需大雨丘陵；五星需浓雾暗流。天气不符时，清关后再次点击快速采集可重访事件。七星需雪原第五层提交三份汤药。

自动存档随操作写入当前浏览器 localStorage，手动存档为独立槽位。浏览器与访问地址不同，存档不互通；清除站点数据会清除存档。设置按钮展开GM工具，可恢复状态、空投非剧情物资、跳日、重置解谜步数。新开局需确认，保留手动存档。

## 实现与验证范围

12个区域各5层、26种敌人、35个制造配方、6设施、6项状态（生命、饱食、水分、外伤、内伤、精神）、季节天气、夜袭、伙伴、四个逃生结局与死亡总结均已实现。

规则测试通过实际探索、战斗、解谜、事件、制造资源判定触发A/B/C/D，使用GM补给与治疗缩短重复生存过程；这些测试验证路线可达性，不代表完成无GM的长期平衡验收。

这是独立的非商业致敬原型，未使用原游戏美术、音频、代码或文案资源。当前没有创建远程仓库、提交、推送或线上发布。
