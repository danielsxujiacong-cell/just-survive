# 荒野日记 · 孤岛重制版 v3.0

Vite + React + TypeScript + Tailwind CSS + Lucide。海图、动画和天气由 SVG/CSS 绘制，音效与连续环境音由 Web Audio 合成；没有外部静态资源请求。

## 启动与验证

双击 `启动游戏.cmd`。命令行方式：`npm install`、`npm run dev`，打开终端显示的本地地址。

- `npm run build`：TypeScript 检查与生产构建，输出 `dist/`。
- `npm test`：规则测试、240 次完整通关仿真、全岛内容巡查。
- `npm run test:balance`：仅运行全结局与全岛巡查仿真。
- `tests/results/no-gm-report.json`：六天赋 × 十种子 × 四结局的逐次结果、GM 调用数与当前源码 SHA256。
- `tests/results/content-survey.json`：正常开局走遍全部区域、触发 60 个奇遇、收集 12 篇残页的独立巡查记录。
- `tests/results/browser/`：真实浏览器交互验收截图与记录。

`node_modules/`、`dist/`、构建缓存与日志在 `.gitignore` 中排除。

## 游玩说明

选择六种幸存者出身之一。初始营地有小刀、火把、食物和基础建材；先造净水捕兽设施与石斧，探索海岸和竹林，再制造并装备竹枪。

海图选区后点击“整装出发”。小人沿四段路线自动行军，每段消耗游戏时间；奇遇会暂停行军。可消耗藤条处理滑坡、用生肉引开夜行狼群、拾取漂流瓶、辨认路标，或选择强行突进。紧急折返仍需支付回程时间。出门后无法使用营地储物箱。

每区五层，清关后开放快速采集。每区有五个独立多分支奇遇，共 60 个；第一次发现对应记录时收录该区幸存者日记残页。沉船密码舱线索为电台“三短一长”，残页明确记有 `3147`，也可制作铁撬棍强拆。图鉴继承发现过的物品、生态、奇遇、12 篇残页与四个结局印章；新周目重新选择天赋，重置物资和探索进度。

战斗选择头部、四肢/翅膀/尾部、躯干进行攻击。战场显示坐标和1—4格间距。长矛可隔位压制近战敌人；头部难命中但伤害高且可能眩晕；肢体攻击限制敌方移动并破甲；躯干更易命中。双方会受到流血、中毒、麻痹、定身、破甲影响，敌人低血量会狂暴。战斧、长矛、燧发枪、吹箭有专属战技。白狼撕咬可流血定身。战斗使用补给会消耗一个完整回合；绷带止血、汤药和抗生素解毒。

营地制造从背包与储物箱共同取材；离营仅能用背包。出门前装入补给、武器、弹药、火把和防寒/防毒装备。火把会在部分奇遇中消耗，要及时补充。回营可一键存入战利品，装备和随身火把、面具、背包保留。满负重时重要剧情物资送回营地，普通物资无法带走。

八种设施包括火炉、工坊、药台、床、净水捕兽、防御栅栏、草药种植箱、雨水收集器。种植需种子与纯净水，24小时后收获并返还种子；雨水收集器清晨产水，大雨增产。每三天睡眠期间有夜袭，可预置捕兽夹与火墙，战报逐轮展示防线、伤害与战利品。20:00—22:00入睡恢复更多。外伤与内伤的数值越高越健康。

携带钓鱼竿前往海岸或暗流，点击垂钓。游标在绿色安全区内时收竿，积累100进度获得海鲈鱼、电鳗或深海珍宝；张力达到100会断线。水手天赋扩大安全区。

伙伴页面管理白狼、骆驼和库鲁。逃生工程提供实时条件清单：

- A：造船图纸、库鲁五星赠铁木、沉船航海帆布，以及木材50、藤条30、烤肉20、纯净水20，回营建船。
- B：十步内解谜发现研究所，击败博士取得通行证、硬盘、制服，第15天之后的偶数日前往海岸。
- C：超过十步解谜或主动激活地脉，火山第五层用黑曜石10、古代合金5、兽皮15加固隔热舱，可主动引爆逃生。
- D：晴天海岸、雨天丘陵、库鲁五星、明暗盘、浓雾暗流、遗迹守关、雪原祭坛分别取得七颗龙珠，回营召唤。雪原要求毛皮大衣和火把，祭坛消耗汤药3份。

## 存档与验收边界

自动存档和独立手动槽位保存在当前浏览器 localStorage。不同地址与浏览器不互通；清除站点数据会清除存档。v1存档会补齐新系统字段；旧战斗若缺少新状态结构，会退出该次遭遇，保留区域进度。新开局保留手动存档和发现图鉴。音效按钮切换环境音与操作音，设置菜单保留原有GM工具。

正式通关仿真只经 `act()` 正常操作推进，从第1天08:00开始；不直接改写时间、天气、物资、战斗或任务进度，不调用GM，不直接调用结局处理器。每步检查负重、负物资、死亡和操作上限。Agent 会备粮、治疗、睡眠、升级、制造、补充消耗掉的火把，等待正常天气与船期。濒死抢救属于游戏规则，会真实消耗药物，并在报告中单独计数。测试覆盖所列十个种子与六种天赋，不将有限仿真表述为对所有随机情况的数学保证。

这是独立非商业致敬游戏，未使用原游戏美术、音频、代码资源。本次开发未创建远程仓库、提交、推送或线上发布。

## v3 真人体验升级

- 海图上方的生存指南针可折叠，每阶段提供2—3条建议；点击A/B/C/D追踪对应逃生目标，金色呼吸信标标出缺少物资与剧情所在区域。条件齐备会提示启动逃生。
- 「一键卸货入库」保留当前装备、随身工具及核心口粮药品，材料与多余战利品入库。「最佳整备」从已有储物中选择战力/耐久合适的装备与可用弹药，补齐4份熟食、4净水、外伤/内伤药各2，限制在40%负重预算内；物资不足会明确列出缺口，不会凭空生成物品。行囊支持1/5/10/全部批量存取。
- 区域5/5后可现场安全扫荡，白狼结伴后可在营地直接委托；每轮2小时，饱食与水分消耗翻倍。获得整轮普通资源，不代做特殊剧情或天气龙珠事件。
- 海图增加沙洲、森林、雪原、火山分色与纹理，溶洞、遗迹、沉船手绘地标，当前角色篝火徽标，以及流动行军路线。
- 快捷键：战斗1/2/3=头/躯干/肢体；Q重击、W远程、E白狼、R合适药剂、A前进、D后撤、F战技、T突刺、G投网、Esc逃离。探索Space推进；奇遇1/2/3选择；垂钓Space收竿、Esc放弃；明暗盘1—9直接翻格，方向键选格、Space/Enter翻转、Esc暂离。输入密码时不会截获数字输入。
- GM默认完全隐藏，经设置菜单或F9打开；实际使用后本周目永久标记「调试模式存档」，纪念卡也会标注。
- 天赋选择后播放海难序章，可Space/Enter跳过且不消耗生存时间。四个结局有独立SVG演出与战报，时间轴记录真实伙伴、解谜、守关日期；纪念卡可预览并下载1000×1250 PNG。

`tests/results/qol-click-reduction.json`比较相同种子42、相同通关策略下旧式操作与批量存取/扫荡操作的四路线结果。测试得到32%—57%的操作减少；这是固定种子对比，不表示所有玩家与随机情况都减少相同比例。

真实浏览器回放入口：启动开发服务后访问 `/tests/browser-harness.html`，其存档来自零GM仿真、使用独立存档键，不覆盖玩家数据；测试入口不打包进生产 `dist/`。用 `npm run test:balance` 可重新生成通关证据，完整 `npm test` 同时生成四条QoL通关回放。
